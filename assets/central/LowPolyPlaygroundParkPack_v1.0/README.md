# Low Poly Playground & Park Pack (Free)
by reodesuxz

30 low poly playground and park props: slides, swings, benches, fountain, gazebo and more.

## Contents
- FBX/  - one .fbx per model (Unity, Unreal, Godot, Blender)
- GLB/  - one .glb per model (Godot, three.js, Babylon.js, web)
- OBJ/  - one .obj + .mtl per model
- Playground_AllAssets.blend - every model in one Blender file (Blender 4.3+)

## Specs
- Total: 4996 triangles for all 30 models (56-396 tris each)
- Flat-shaded, simple shared materials (no textures needed)
- Real-world scale in metres, pivot at the base centre
