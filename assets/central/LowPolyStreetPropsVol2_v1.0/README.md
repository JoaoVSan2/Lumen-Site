# Low Poly Street Props Vol. 2 (Free)
by reodesuxz

26 low poly city street props: traffic lights, signs, benches, hydrants, bins and roadwork.

## Contents
- FBX/  - one .fbx per model (Unity, Unreal, Godot, Blender)
- GLB/  - one .glb per model (Godot, three.js, Babylon.js, web)
- OBJ/  - one .obj + .mtl per model
- Street2_AllAssets.blend - every model in one Blender file (Blender 4.3+)

## Specs
- Total: 1964 triangles for all 26 models (12-156 tris each)
- Flat-shaded, simple shared materials (no textures needed)
- Real-world scale in metres, pivot at the base centre
