# Solados — Referências de personagens

Esta pasta reúne desenhos, artes e imagens de referência dos personagens da HQ **Solados**, para preparar suas versões 3D estilizadas no Lumen Society.

## Organização
- `referencias/`: desenhos, artes conceituais e imagens de referência enviados pelo autor.
- `personagens/`: materiais organizados por personagem durante a preparação dos modelos.

Envie os arquivos originais sempre que possível e mantenha os nomes dos personagens nos arquivos ou em subpastas próprias.
