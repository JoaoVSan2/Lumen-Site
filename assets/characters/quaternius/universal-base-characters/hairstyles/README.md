# Hairstyles

Eight hairstyle/accessory meshes are included:
`Eyebrows_Female`, `Eyebrows_Regular`, `Hair_Beard`, `Hair_Buns`, `Hair_Buzzed`, `Hair_BuzzedFemale`, `Hair_Long`, and `Hair_SimpleParted`.

The archive provides two placement variants:
- `origin-at-zero/`: standalone meshes positioned at the origin.
- `rigged-to-head-bone/`: versions rigged to the head bone, useful for attaching to an animated character.

Each glTF mesh must stay with its matching .bin and referenced hair textures.
