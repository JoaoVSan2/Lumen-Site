# Source package audit

- Original archive: `Universal Base Characters[Standard].zip`
- Archive size: 128,968,391 bytes (about 123 MiB)
- ZIP entries: 128 total, including directory entries
- Extracted files: 112
- Extracted size: about 127 MiB
- Package: Standard FREE version
- License supplied in archive: CC0 1.0 Universal
- Creator credit in supplied license: Quaternius

The archive includes:
- Base Characters: female and male full-body models, glTF (Godot/Unreal) and FBX (Unity).
- Base-character textures: eye, hair, skin/base-color, normal and roughness maps.
- Hairstyles: 8 options (female eyebrows, regular eyebrows, beard, buns, buzzed, buzzed female, long, simple parted).
- Hairstyles supplied as origin-at-zero and rigged-to-head-bone variants.
- Hair textures: base-color and normal maps.
- An Unreal Engine import note and a preview image.

Important: the free Standard archive is a subset of the full/source package. The source license text explicitly says it contains only a portion of the models.

Binary upload status: the current GitHub connector supports text/blob operations but this session has not transferred the large binary model and texture files. This repository folder currently contains the folder structure and audit documents, not a complete runnable copy of the ZIP.
